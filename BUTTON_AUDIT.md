# Button coverage

The Android regression suite exercises local space creation/cancel, offline compose/send/reopen, privacy/retry, navigation, Nearby entry/exit and radio prerequisites, calendar validation/create/delete, phone form validation/cancel/offline continuation, call prerequisites and lock. Password cases cover wrong-password rejection, correct entry and cancel. Native cloud transport has a separate optional test.

Actual provider SMS delivery, owner confirmation on physical phones, two-phone radios and real relayed calls remain service/device checks. No button displays simulated successful calls or fabricated message replies.
